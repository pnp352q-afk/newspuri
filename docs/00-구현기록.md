**정한 것과 까닭**

- **언어는 Node.js**, 바깥 부품은 Claude SDK·zod 둘뿐. DB 는 Node 내장 SQLite(`node:sqlite`, Node 22.5 이상).
- **사건 연구 셈법**: 기준 = 공시일 전날 종가. DART 목록에 접수 «시각»이 없어서, 장중 공시의 첫 반응을 놓치지 않으려고 전날 종가를 기준으로 잡았다. 1일 = 공시 당일 하루. 시장지수 대비 초과수익률. **중앙값**(평균은 한두 건 폭등에 끌려간다). 정정 공시는 빼서 같은 사건을 두 번 세지 않는다. 표본 30건 미만은 값을 싣지 않는다.
- **주가 원천은 아직 없다** — KRX 가 허락 대장에서 allow=아니오. 그래서 사건 연구는 틀과 검산만 끝냈고, 화면의 막대는 «견본» 값이다.
- **판단 네 칸**: 호재 쪽 · 악재 쪽 · 중립 · 판단 어려움. «오른다/내린다»가 아니라 «흔히 이렇게 읽힌다». 놀라움은 원문 숫자로만 판단하고, 시장 기대치가 필요하면 «알 수 없음».
- **근거는 원문 글자 그대로** — 저장 전에 원문과 대조해 없으면 버린다. 원문도 `document` 표에 보관해 `check.js` 가 인터넷 없이 다시 대조한다.
- **Claude 거절 대비**: 서버 쪽 대체 모델(`fallbacks: "default"`)을 켰다. 거절되면 서버가 알맞은 모델로 한 번 더 해 본다.
- **색**: 한국 관례대로 빨강 = 시장보다 더 오름, 파랑 = 덜 오름.

**검증한 것 (이 날)**

- 분류기: 실제 DART 제목 꼴 8가지(«ㆍ» 가운뎃점, [기재정정] 포함)를 바르게 나눔.
- 수집기(가짜 DART): 020 한도 → 쉬고 다시 · 중간 오류로 끊기면 «받은 칸 3/4 · 20260902 2쪽에서 끊김» · 다시 돌리면 남은 3쪽만 받음 · 다 받은 뒤엔 호출 0번.
- 사건 연구(가짜 주가 40종목, 당일 +2%p·이후 4일 +0.25%p씩): 1일 +2.00 · 5일 +3.04 · 20일 +3.08 — 기대와 맞음.
- 해석기(가짜 Claude·가짜 DART ZIP): 정상 저장 · 원문에 없는 근거 → 버림 · «사세요» → 버림 · 거절 → 실패로 기록.
- 점검: 일부러 넣은 잘못 5가지(금지말 2·가짜 근거·2줄짜리 쉬운 말·표본 12건 값)를 모두 잡음 · `--deploy` 는 견본 카드를 막음.

**아직 안 한 것**

- 실제 DART 열쇠로 돌려 보기(작업 공간에서 DART 접속이 막혀 있었다 — 대표 PC 에서 할 일).
- 주가 원천(KRX 이용 조건 확인 → 허락 대장 → `import_prices.js`).
- 법률 확인(`docs/법률확인.md`).
