# 뉴스풀이 인수인계서 (2026-09-25)

이 문서 하나로 이어받을 수 있게 썼다. 규칙은 `CLAUDE.md`, 날짜별 경과는 `docs/00-구현기록.md`, 기획 근거는 `docs/01-기획-조사.md`.

## 1. 한 줄 요약

주가에 영향을 주는 **공시**를 모아 일반인이 알아듣게 **쉬운 말 3줄 + 원문 근거 + 과거 비슷한 공시 뒤 움직임(시장 대비 중앙값)** 으로 보여 주는 **해석 서비스**. 예측·투자 자문이 아니다.
1단계 코드는 끝났고, **실제 공시 수집까지는 대표 PC 에서 돌았다**. 실제 Claude 해석과 실제 주가 통계는 아직 한 번도 돌지 않았다.

## 3. 처음 설치 (윈도우 기준, 맥·리눅스도 같다)

```
git clone https://github.com/pnp352q-afk/newspuri
cd newspuri
npm install
npm run sample      # 견본(가짜) 공시 8건으로 끝까지 — 마지막에 [점검 통과]
npm run serve       # http://127.0.0.1:3320
```

- Node.js **22.5 이상**(내장 `node:sqlite` 를 쓴다). 대표 PC 는 v26.7.0 에서 돌았다.
- 윈도우 PowerShell 에서 `npm` 이 «스크립트를 실행할 수 없습니다»로 막히면 `npm.cmd` 로 부른다.
- 바깥 부품은 `@anthropic-ai/sdk`, `zod` 둘뿐.

### 열쇠 넣기

열쇠 폴더: 윈도우 `C:\keys\`, 그 밖 `~/.keys/`, 또는 환경변수 `NEWSPURI_KEYS`.

| 파일 | 내용 |
|---|---|
| `.dartkey` | DART 인증키 40글자 |
| `.anthropickey` | Claude API 열쇠(`sk-ant-…`). 환경변수 `ANTHROPIC_API_KEY` 가 있으면 그쪽이 먼저 |

메모장은 `.txt` 를 몰래 붙이거나 저장이 빠지기 쉬워 대표 PC 에서 세 번 실패했다(`.dartkey.txt` 도 읽게 고쳐 두었다). PowerShell 에서 가려진 입력으로 저장하는 편이 확실하다:

```
$s = Read-Host "DART 열쇠" -AsSecureString; $k = [regex]::Match([Net.NetworkCredential]::new('', $s).Password, '(?<![0-9A-Za-z])[0-9A-Za-z]{40}(?![0-9A-Za-z])').Value; if ($k) { Set-Content -NoNewline -Encoding ascii C:\keys\.dartkey $k; "저장됨: " + (Get-Item C:\keys\.dartkey).Length + "글자" }
```

## 4. 명령

| 명령 | 하는 일 | 비용 |
|---|---|---|
| `npm run fetch -- --days 7` | DART 공시 목록 → `data/news.db`. 끊기면 다시 돌리면 이어받음. `--type B` 로 종류 거르기 | 없음(DART 하루 호출 한도 약 2만) |
| `npm run stats` | 공시가 있었던 최근 날의 종류별 건수·상장사 수·해석된 수 | 없음 |
| `npm run interpret -- --limit 5` | 상장사 공시를 Claude 로 해석(분류표 차례대로, 공시마다 한 번) | **있음** — 어림 건당 100~300원(실측 전) |
| `npm run study` | 과거 5년 사건 연구(주가 자료 필요) | 없음 |
| `npm run build` | 화면 자료 `web/today.json` | 없음 |
| `npm run check` | 규칙 점검. 공개 배포 전엔 `node src/check.js --deploy` | 없음 |
| `npm run serve` | 화면 서버 127.0.0.1:3320 | 없음 |
| `npm run sample` | 견본으로 전 과정 | 없음 |

## 5. 구조

```
fetch_dart.js ─→ data/news.db ─→ interpret.js (Claude · 원문도 document 표에 보관)
                     ↑                  │
import_prices.js ─→ price ─→ event_study.js ─→ event_stats
                                        ↓
                           build_web.js ─→ web/today.json ─→ server.js ─→ web/index.html
check.js — 배포 전 문지기
```

| 파일 | 요점 |
|---|---|
| `config/sources.csv` | 허락 대장. `allow=예` 인 출처만 수집(`src/lib/ledger.js`). 지금: sample·dart·ecos 예 / krx·fred·news 아니오 |
| `config/event_types.csv` | 공시 종류 18가지(찾는 말·흔한 해석·쉬운 설명·주의). **줄 차례 = 해석 차례** |
| `config/forbidden.csv` | 금지말(매수·매도 권유, 주가 단정) |
| `config/llm.json` | 모델 `claude-opus-5` · effort high · 원문 15만 자 넘으면 보류 |
| `src/lib/classify.js` | 공시 제목 → 종류. «ㆍ»(U+318D)·괄호·띄어쓰기를 지우고 견준다 |
| `src/lib/rules.js` | 근거가 원문에 글자 그대로 있는가 · 3줄인가 · 금지말 — 해석 저장 전과 점검에서 같이 쓴다 |
| `src/lib/unzip.js` | DART 원문 ZIP 을 바깥 부품 없이 푼다 |
| `fixtures/` | 견본(가짜) 공시. 회사 이름 끝에 «(견본)», DB `source='sample'` |

DB 표: `disclosure`(공시 목록) · `fetch_done`(이어받기 장부) · `document`(원문) · `interpretation`(해석 JSON) · `price`(종가) · `event_stats`(사건 연구).

## 6. 지금 상태 — 검증한 것 / 안 한 것

**검증함**

- 견본 전 과정 `[점검 통과]` — 클라우드 작업 공간과 대표 PC 모두.
- 실제 DART 목록 수집(대표 PC, 2026-09-25): 받은 칸 23/23, 1,727건. 주말·추석(9/24~26)은 0건으로 달력과 맞다.
- 9/23 하루 683건 → 해석 대상(상장사·기타 제외) 182건.
- 가짜 DART 로: 020 한도 → 쉬고 다시, 끊기면 위치와 «받은 칸 N/M» 보고, 이어받기.
- 가짜 주가 40종목으로 사건 연구 검산: 1일 +2.00 · 5일 +3.04(기대 약 +3.0).
- 가짜 Claude 로: 정상 저장 · 원문에 없는 근거 → 버림 · «사세요» → 버림 · 거절 → 실패 기록.
- 점검이 일부러 넣은 잘못 5가지를 모두 잡음. `--deploy` 는 견본 카드를 막음.
- 화면: 데스크톱·휴대폰·어두운 모드, 콘솔 오류 0.

**아직 안 함 (이어받아 먼저 볼 것)**

1. **실제 Claude 해석을 한 번도 안 돌렸다.** Claude 열쇠를 만들기 직전에 멈췄다. 처음엔 `--limit 5` 로 비용과 품질을 잰다.
2. **실제 DART 원문(document.xml) 풀기를 실물로 확인 못 했다.** 가짜 ZIP 으로만 시험했다. 실물에서 글자 인코딩(UTF-8 가정)·여러 파일 ZIP·아주 긴 원문을 확인할 것.
3. **주가 원천이 없다.** KRX 이용 조건 확인 → 허락 대장 `allow=예` + 근거 → `import_prices.js`(CSV: 종목코드,날짜,종가 · 지수는 `IDX_KOSPI`/`IDX_KOSDAQ`). 그 전까지 화면의 «과거 움직임»은 견본 값이며, 실제 공시 카드에는 «자료 없음»이 뜬다.
4. **사건 연구용 과거 5년 공시**를 아직 안 받았다. `--type B`(주요사항보고)·`I`(거래소공시) 로 좁혀 받는 것을 권한다(전부 받으면 하루 한도에 걸린다).
5. **«기타» 497/683건** — 분류표를 늘릴 여지가 크다. `stats` 로 보고 `event_types.csv` 에 줄을 더한다.
6. **법률 확인 9개 모두 빈칸.** 대표가 전문가에게 확인하기 전에는 유료화·공개 배포하지 않는다.
7. **허락 대장의 DART·ECOS 근거가 «대표 확인 전».** 점검이 매번 «주의»로 알린다.
8. 서버 배포는 설계만 있다(결과 파일만 올리는 구조). 어디에 올릴지 정해지지 않았다.

## 7. 되돌리지 말 것 (정한 까닭)

- **예측이 아니라 해석.** «호재 쪽/악재 쪽/중립/판단 어려움» 네 칸은 «흔히 이렇게 읽힌다»이지 전망이 아니다.
- **근거는 원문 글자 그대로.** 저장 전 대조, 원문 보관, 점검에서 다시 대조. LLM 이 지어낸 숫자를 막는 유일한 장치다.
- **표본 30건 미만은 값을 싣지 않는다.** 중앙값을 쓴다(평균은 한두 건 폭등에 끌린다). 기준은 공시 전날 종가(DART 목록에 접수 시각이 없다).
- **견본과 실제를 섞지 않는다.** 실제 해석이 하나라도 있으면 화면은 실제만. 실제 공시에 견본 통계가 붙으면 점검이 떨어뜨린다.
- **허락 대장을 지나지 않은 수집은 없다.** 뉴스 원문 재게시 금지(제목·요약·링크만).
- **해석은 상장사만.** 주가가 없으면 과거 움직임을 못 붙인다.
- **무거운 계산은 PC, 서버는 결과만.**
- **열쇠는 파일에서만**, 코드·로그·대화에 값으로 쓰지 않는다.

## 8. 대표(기획자)와 일하는 법

- 비개발자 기획자. 설명은 한국어로, 쉬운 말로. 전문용어 옆에 풀이.
- 명령은 **복사해 붙일 한 줄 + 어디에 붙이는지**, **한 번에 한 단계**, 끝날 때마다 확인.
- 코드 고치기 전에 «무엇을 왜» 한 줄. 끝나면 화면을 직접 확인하고 무엇을 확인했는지 말한다.
- 대표 계정에 대신 로그인하지 않는다. 비밀번호·열쇠를 대화로 받지 않는다.
- 대표는 같은 PC 에서 다른 프로젝트(입지맵 `C:\x` 등)도 한다 — **폴더를 섞지 않는다.** 뉴스풀이는 `C:\newspuri`.
