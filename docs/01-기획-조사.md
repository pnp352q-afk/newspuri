# 뉴스풀이 기획 조사 (2026-09-25)

대표 요청: «주식 전문가가 주가에 가장 민감한 뉴스·정보를 일반인이 알아듣게 풀어 주는 시스템». 아래는 착수 전에 정리한 조사 내용이며, 서비스 방향과 단계 계획의 근거다.

## 0. 출발점 — 무엇을 약속하지 않는가

- 주가를 정확히 맞히는 모델은 지금도 없고, 컴퓨터 성능이 10배가 되어도 생기지 않는다. 모두가 같은 예측을 알면 그 예측이 곧 가격에 반영돼 사라진다(재귀성). 최상위 퀀트도 적중률은 50%를 조금 넘는 수준이고, 수많은 종목·거래로 작은 우위를 쌓는다.
- 그래서 이 서비스는 **«내일 오른다/내린다»가 아니라 «이 뉴스가 왜 중요하고, 과거 비슷한 일 뒤 어떻게 움직였나»를 푸는 해석 서비스**다.
- **법**: 불특정 다수에게 대가를 받고 투자 판단 정보를 주면 유사투자자문업 신고 대상일 수 있고(자본시장법), 1:1·양방향(단톡방 등)은 투자자문업 등록 대상이다. 질문 목록은 `docs/법률확인.md`.

## 1. 주가를 크게 움직이는 정보 (민감한 순)

| 순위 | 종류 | 설명 |
|---|---|---|
| 1 | 실적 발표·잠정실적 | 숫자 자체보다 **시장 기대와의 차이**가 움직인다 |
| 2 | 금리·통화정책(한국은행, 미 연준) | 돈의 값이 바뀌면 모든 주식의 값이 같이 바뀐다 |
| 3 | 물가(CPI)·고용 | 금리를 미리 짐작하게 한다 |
| 4 | 수급(외국인·기관 순매수, 공매도, 신용잔고) | 한국 시장에서 특히 강하다 |
| 5 | 기업 중대 공시(유상증자·전환사채·대주주 매도·M&A·수주·자사주) | 증자·CB 는 대개 악재, 자사주 소각은 대개 호재 |
| 6 | 정책·규제·세금 | 업종 전체가 함께 움직인다 |
| 7 | 환율·유가·원자재 | 수출/수입 기업의 희비 |
| 8 | 공급망·경쟁사 소식 | 사슬을 타고 번진다(예: 미국 반도체 실적 → 국내 반도체) |
| 9 | 지정학·재난 | 짧고 크게 흔들린다 |
| 10 | 증권사 목표가·의견 | 영향이 작고 짧다 |

## 2. 심리 선행지표 (2단계 «심리 온도계» 재료)

- 공포: VKOSPI, VIX, 풋/콜 비율
- 빚투: 신용융자 잔고, 반대매매 금액
- 대기 자금: 고객예탁금, CMA·MMF 잔고
- 개인 쏠림: 개인 순매수 급증, 신규 계좌 수, 종목토론방 글 수(과열 → 흔히 반대로 작용)
- 관심도: 검색량, 뉴스 건수·감성
- 해외: CNN 공포·탐욕 지수, AAII 설문, 신용 가산금리
- 경기 심리: 소비자심리지수(CCSI), BSI, 장단기 금리차

**극단값일 때만 의미가 있다.** 평소 오르내림은 잡음에 가깝다 → 화면에서도 극단값일 때만 강조한다.

## 3. 데이터 지도 (한국 기준)

| 묶음 | 예 | 받는 곳 |
|---|---|---|
| 가격·거래 | 시세·거래량·투자자별 매매 | KRX 정보데이터시스템, 증권사 API |
| 공시 | 수시공시·정기보고서 | **OpenDART**(지금 쓰는 중) |
| 거시 | 금리·물가·환율·수출 | 한국은행 ECOS, KOSIS, 미 FRED |
| 뉴스·글 | 기사·리포트·실적발표 녹취 | 뉴스 API(제휴·약관 확인) |
| 대체 데이터 | 카드 매출·위성·앱 다운로드·채용·통관 | 대부분 유료 |
| 관계 | 공급망·지분·경쟁사 | DART 로 직접 구축 |

모든 출처는 `config/sources.csv`(허락 대장)를 지나야 한다.

## 4. 지금 쓸 수 있는 예측·해석 기법

1. **팩터 + 부스팅 나무(LightGBM 등)** — 실전 주력. «다음 달 어느 종목이 상대적으로 나을까» 줄 세우기.
2. **시계열 딥러닝**(Transformer 계열, TFT, 시계열 기초모델 TimesFM·Chronos·Moirai) — 주가에서는 아직 성과가 약하다.
3. **LLM 뉴스·공시 해석** — 가장 크게 발전한 부분. 사건 종류·방향·놀라움을 구조화. **이 서비스의 핵심 엔진.**
4. **그래프 신경망** — 공급망·경쟁 관계로 파급을 계산(3단계).
5. **사건 연구(이벤트 스터디)** — 과거 같은 종류 사건 뒤 평균·중앙값 움직임. 가장 단순하지만 일반인에게 설명하기 가장 좋다(1단계에 구현).
6. 최상위 퀀트의 성패는 모델보다 **데이터 품질과 검증 규율**(미래 정보 차단, 워크포워드 검증)에서 갈린다.

## 5. 컴퓨터가 10배 좋아지면 가능해지는 것

10배는 혁명이 아니라 한 단계 도약이다. 지금은 비싸서 못 하는 것들이 열린다.

1. **시장 디지털 트윈** — 개인·외국인·연기금·단타 등으로 행동하는 LLM 투자자 수십만을 가상 시장에 풀어 «금리 0.5%p 인상이면?»을 수천 번 돌려 **시나리오별 확률 분포**를 얻는다.
2. **실시간 세계 모델** — 전 세계 뉴스·공시·실적발표 음성·위성·선박 이동을 한 멀티모달 모델이 동시에 읽고 파급을 갱신.
3. **인과 추론** — «같이 움직였다»가 아니라 «이것 때문에»를 가리고, «그 뉴스가 없었다면?» 반사실 계산을 종목마다 매일.
4. **개인별 해석 에이전트** — 사용자의 보유 종목·성향에 맞춰 «당신 계좌에 어떤 의미인지».
5. **상시 적대적 검증** — 한 모델이 예측하면 여러 모델이 «틀릴 이유»를 찾아 과적합을 걸러 낸다.

남는 한계: 모두가 같은 모델을 쓰면 우위는 사라지고, 처음 보는 사건은 계산이 아니라 추측이다. 10배 컴퓨팅의 가치는 **맞히기보다 이해시키기와 대비시키기**에 있다.

## 6. 단계 계획

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 공시 수집 → LLM 해석(쉬운 말 3줄·근거) → 사건 연구 → 카드 화면 → 점검 | 코드 완료 · 실제 해석은 Claude 열쇠 대기 · 주가는 KRX 허락 대기 |
| 2 | 뉴스 + 심리 온도계(VKOSPI·신용잔고·예탁금·개인 순매수·검색량, 극단값만 강조) | 안 함 |
| 3 | 공급망 그래프(이 소식이 번질 회사) | 안 함 |
| 4 | 예측 모델(팩터+LightGBM, 공시 사건 신호) — 내부 검증 전용, 성적표 공개 | 안 함 |
| 5 | 가상 시장 시나리오(LLM 투자자 에이전트) | 안 함 |
