# 법률 확인 목록 (유료화·공개 전에 전문가에게 확인)

> 이 문서는 **질문 목록**이지 법률 판단이 아니다. 금융감독원·변호사에게 확인한 뒤 «확인 결과» 칸을 채운다.
> 모두 채우기 전에는 **유료화하지 않는다**(절대 규칙 9).
